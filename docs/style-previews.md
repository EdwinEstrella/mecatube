# Vistas previas de estilos visuales para Mecatube

Esta guía describe cómo generar y guardar las imágenes de vista previa para los 20 nuevos estilos visuales del catálogo.

### Pasos para añadir una vista previa:
1. Copia el prompt en inglés del estilo correspondiente.
2. Genera la imagen en Google Flow en formato cuadrado **1:1**.
3. Descarga la imagen generada en formato PNG.
4. Guárdala con el nombre exacto de archivo indicado en la ruta `src/assets/styles/<id>.png`.
5. Reinicia la aplicación para que el selector de estilos muestre la nueva miniatura en lugar del recuadro provisional.
